让我们来设计一款游戏，讲述小岛经济学中的一切

这个游戏，唯一的要素是2个人，A，B，以及一根时间轴
如果你点开A的用户界面，你会发现

```

user:A
行动点：10
劳动：捕鱼(5)
积蓄：20
资本：一个渔网
消费：5
```

随着时间流逝，行动点会不断增多
```
行动点：10->20
```

行动点可以转化为劳动
```
行动点：20->10
劳动：捕鱼(5->15)
```

资本施加在劳动上，可以以一定的比例将劳动转化为积蓄
```
劳动：捕鱼（15->5)
资本：渔网
积蓄：20->30

劳动：捕鱼（15->5)
资本：无
积蓄：20->22
```

积蓄和行动点，在有一定风险的情况下可以转化为资本
```
积蓄：20->0
行动点：10—>0
资本：无->一个渔网
成功概率：20%
```

随着时间推移，积蓄会因为消费而减少
```
时间过了一天
消费：5
积蓄：20->(20-5=15)
```

行为：给别人积蓄(A给B)
```
user:A
积蓄：20->15

user:B
积蓄：5->10
```

行为：给别人资本（A给B）
```
user:A
资本：一个渔网->无

user:B
资本：无->一个渔网
```

契约（两个行为的逻辑绑定）（行为1，条件，行为2）

借款/贷款（可分为商业贷款，消费贷款和应急贷款）
```
A和B约定，

时间点1：
A给B，10个单位的积蓄

时间点2：
B给A，15个单位的积蓄
```

投资：
```
A和B约定，

时间点1，
A给B，10个单位的积蓄

如果B在时间点2前创造出了资本：一个渔网
在时间点2，
B给A，20个单位的积蓄
```

事件：意外，导致资本与积蓄的减少
```
意外：自然灾害
资本：一个渔网->无
积蓄：15->0
```

 行为：创立合伙公司
 ```
 A和B投入积蓄和资本，创立合伙公司C
 
 user:A,B
 积蓄：-5
 资本：-一根渔网
 
 (new)corporation:C
 积蓄：+10
 资本：2个渔网
 员工：A,B
 ```

整个游戏随着时间变化，有一个全局变量：经济
```
在1天内
user:A,B
积蓄:每人+10

当日经济：10+10=20
```
所以，经济和总资本有关
