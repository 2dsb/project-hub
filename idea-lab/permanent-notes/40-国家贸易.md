# 定义
世界价格：一种物品在世界市场上通行的价格
关税：对进口商品征收的一种税
# 国家贸易
10大原理：5.贸易可以使每个人的状况变好
## 没有贸易时的均衡
isoland 是一个国家，最初与世隔绝，没有国际贸易。在这种情况下，该国纺织品市场由本国的买者和卖者组成，形成均衡数量和均衡价格
## 如果允许自由贸易
1. 问题1：isoland 会成为纺织品进口国还是出口国？
如果国内价格大于世界价格，成为进口国；
反之如果国内价格小于世界价格，成为出口国

这反映了该国在纺织品生产上是否具有比较优势

2. 问题2：赢家和输家是谁？
假设isoland 是小型经济体，无法影响世界价格（价格接受者）
如果它是出口国，则当国内价格上升到等于世界价格，国内供给量上升，国内需求量下降，差量就是出口量
![[IMG_0161.jpeg]]
纺织品生产者状况变好，消费者状况变坏，总剩余增加


如果它是进口国，类似的，生产者状况变坏，消费者状况变好，总剩余增加
# 关税
关税只影响进口国，让进口纺织品的价格提升到世界价格之上，减少与国内价格的差距，导致买者状况变坏，卖者状况变好，减少进口量，并使国内市场向没有贸易时的均衡移动
关税会产生无谓损失
# 国际贸易的其他好处
1. 增加物品多样性
2. 规模效应降低成本
3. 增加竞争
4. 加强思想交流

# 限制贸易的观点
1. 消灭工作岗位
     工人可以从纺织品行业转到该国具有比较优势的行业
2. 国家安全论
3. 幼稚产业论
4. 不公平竞争论
     不同国家的企业服从于不同的法律及管制
5. 作为讨价还价筹码的保护论
     问题：威胁可能不起作用
