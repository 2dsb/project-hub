# 经济的两种看法
一种看法是，经济是物品，服务的生产，分配，消费系统
此时经济利用技术，当某种新技术产生时，系统中的一部分被替换，新的升级模块安插进来，机器的其他部分自动重新进行平衡，价格，生产与消费也会相应进行重新调整

新的理解方法是，经济由技术建构，包括2部分：
- 技术部分，经济是对商品，劳务的安排（作为目的，因此，在一定程度上，经济是目的性系统）
- 非技术部分，有活动，决策，物流，资金流等
技术部分为主题，非技术部分围绕技术部分形成

# 新技术导致经济的结构性变化
新技术：
1. 进入经济
2. 替换旧技术，造成一系列机会利基的失去以及随之而来的连锁反应
3. 技术提供了潜在的新元素，引发包含它的新的组织制度的发生（[36 一般意义上技术的演化](../permanent-notes/36-一般意义上技术的演化.md)）
4. 为新一步的技术建立机会利基，这样的机会利基从新技术引起的技术的，经济的，社会的问题中建立，带来进一步解决这些问题的需求
注意，技术不仅有对于经济的影响，还有次生的对于心理等其他方面的影响

# 经济作为技术，自身的演化
同样如[36 一般意义上技术的演化](../permanent-notes/36-一般意义上技术的演化.md)中所述，新的安排方式既会替换取代（一般意义上的经济）中的元素，造成连锁反应；又会创造新的机会利基，产生新需求，并提供新的组合方式

# 经济演化中的不变量
人类行为偏好，论述的现实结构，供求平衡的自明之理等需求

**演化以“问题与解决，挑战与回应”的方式进行**
