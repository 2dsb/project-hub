# C1
个人希望生活更幸福，企业希望投入获得最大回报，但两者资源有限，必须做出权衡。
市场上，价格连接供需，反映稀缺性，并作为信号提供激励，促使权衡改变，调整行为。

当奶茶的价格上涨时，消费者重新衡量“奶茶获得的快乐”和“消费的金钱”，更少地购买奶茶；如果上涨后利润更高，企业更愿意购买奶茶原料，生产更多奶茶；奶茶价格上升反映了需求相对于共给的增加，也通过改变激励，引导个人，企业重新权衡

# C2

第二章说明，市场要有效运行，除了价格，还需要规则基础和纠偏机制。政府通过产权、合同、法律、货币和基础设施降低交易成本；当外部性让价格漏算社会成本或收益时，政府通过税收、限制或补贴修正激励，使外部影响进入决策者的权衡。

“外部性内部化”可以用一句白话理解：
谁的行为影响了别人，就尽量让这个影响回到他的决策账本里。

负外部性是“把漏掉的成本加回去”。
比如工厂污染：

原本企业生产商品，只算原料、人工、设备成本。  
但污染造成的空气变差、居民生病、环境修复成本，被别人承担。  
企业的账本里没有这笔成本，所以它会觉得生产很便宜，生产太多。  
政府征污染税，就是把这部分社会成本加回企业账本里。  
企业一看成本变高，就会减少污染性生产，或者改用更清洁的技术。

正外部性是“把漏掉的收益补回来”。
比如疫苗：

一个人打疫苗，不只保护自己，也降低传染给别人的概率。  
但他做决定时，可能只计算自己的好处和花费，没有把“保护别人”的好处算进去。  
所以社会上接种的人可能太少。  
政府免费提供疫苗或补贴接种，就是把一部分社会收益转化为个人激励。  
个人接种成本降低，就更愿意打疫苗。

所以不是简单“政府让价格回到最优”，而是：
政府试图让个人或企业面对更完整的成本收益表。

# C3
第三章的主线是激励，因为制度会改变人的选择。公共资源中，个人面对的激励是，多使用一点公共资源，自己独占好处，但对公共资源的消耗导致的后果由众人承担，所以每个人都会多拿一点，导致公共资源被消耗；税收中，个人或企业面对的激励是，纳税会消耗钱，所以个人或企业会漏水，转移财产等；委托代理中，代理人面对的激励可能是奖金和职位安全，这与股东的利益不一致，所以代理人可能为了使自己效用最大化而不考虑股东利益。因此，制度设计的关键不只是看政策本意，而是要看制度作为激励，让个人或企业重新权衡带来的结果

在考试内卷中，收益主要来自排名这种相对位置，成本则是实际付出的时间、压力，以及放弃运动、社交、休息等机会。单个人多学时，他可能提高排名，所以对他是理性的；但所有人都多学时，整体排名结构没有改善，大家却都付出更多成本。因此，个体理性导致集体更差的机制是：相对收益不能被所有人同时增加，但绝对成本会被所有人真实承担。

私人收益 + 分摊成本：公共资源、污染。  
相对收益 + 绝对成本：内卷、军备竞赛、排名竞争。

这是激励问题，因为每个人在当前规则下响应个人激励是理性的，但当所有人都这样做时，整体结果可能变差；所以制度设计要让个人觉得划算的选择，也尽量带来更好的集体结果。

制度设计通过规则改变个人面对的成本和收益，让个人重新权衡，并使个人理性的选择尽可能导向更好的集体结果

# C4
管制是为了解决市场外部性，公共资源滥用，危险交易等问题，但会受到政治过程影响，导致腐败，资源错配，创新减少等“管制成本”，所以关键是用好的激励设计，让个人选择尽量接近社会整体利益


第四章是在修正第二章。第二章强调，政府通过提供产权、法律、货币、基础设施等制度基础来降低交易成本，并通过管制、税收或补贴修正外部性等市场失灵。但第四章提醒我们，现实政府也会失败：政府机构缺乏竞争激励，可能效率低；政府掌握的信息有限，可能错配资源；政治过程可能让资源流向有权势的人或既得利益集团；税收会改变工作、投资和消费行为，造成无谓损失；执行方式设计不好，也会制造新的错误激励。因此，公共产品不一定要由政府亲自生产，可以由政府融资和规划，再通过市场竞标让私人部门执行，以结合政府解决供给不足的能力和市场竞争提高效率的能力。

分清楚“应然“和”实然“


第 1 章：市场靠价格和激励运行。  
第 2 章：市场会失灵，政府有必要。  
第 3 章：制度会创造激励，人会响应激励。  
第 4 章：政府也会失灵，政府干预也有激励、信息、政治和税收成本。
