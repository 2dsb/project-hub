[43 小岛经济学的游戏化（静态游戏）](../permanent-notes/43-小岛经济学的游戏化（静态游戏）.md)
各行各业的人们需要统一的"东西”来作为交换货币
货币有固有价值，对于其他商品，根据与“固有价值”的比值，作为其价格

```
货币：鱼（价格1）
```

资本的提高，生产力提高，产生行业与职业
对于每个人，其添加了一个属性：职业，行业
```
user:A
职业：厨师（餐饮业）
```

这时，对于A，他具有了新的属性
```
user:A
行动点：10
劳动：捕鱼(5)
积蓄：20
资本：一个渔网
消费：5
```
对于之前资本+劳动转化为积蓄的流程变为了：
职业决定劳动性质（表中是捕鱼），劳动转化为生产（商品或服务），生产转化为积蓄（以货币衡量）
```
user:A
职业：厨师（餐饮业）
劳动：做菜(15->5)
资本：炊具等
生产：0->10盘菜


生产：10盘菜—>0
积蓄：5->15
```

行为：自然人A把劳动出售给公司C
```
corporation:C
职员：A
劳动：做菜(0->15,A)

```

契约：打工（自然人A向公司C打工）
```
A和C约定
在一个月内，A把劳动给C
一个月后， C给A积蓄
```

C也能将资本施加在劳动上，变为生产 
因此，工资的多少和（资本作用在劳动上获得的生产可以换取的积蓄）有关

比较优势：一个人的行动点转化为不同性质劳动，劳动再转化为生产，进一步变为服务的效率
