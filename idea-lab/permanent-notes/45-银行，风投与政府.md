银行让储户存钱，借贷/投资，并付利息给储户
```
bank:D
资金：10000
```

个人或公司可以和银行签订契约：

个人/公司把储蓄给银行，一段时间后，银行还本金+利息
```
个人A和银行D的契约：
今天，A给D 100资金
一年后，D给A 103资金
```

个人/公司向银行贷款，一段时间后，个人换本金+利率
```
公司C和银行D的契约：
今天，D给C 1000资金
一年后，C给D 1100资金
```

银行给个人/公司投资（类似，不写了）

风险投资机构向风险高的公司投资

```
VC:E
资金：10000
```

个人/公司可以和风险投资机构签订契约
风险投资机构给高潜在利润，高风险公司投资

政府可以颁布政策，改变/控制某些因素：
行为：公布基准利率

```
政府：公布基准利率
```

美联储是美国财政部的衍伸，其政策
```
政策：公布基准利率

原理：经济学家运用集体智慧，推算出特定时段最理想的利率水平，使经济正常运行
比如，美联储可以降低利率，让企业或个人容易借贷，以刺激不景气的经济；
经济繁荣时，应该提高利率，让人们在借贷时三思而后行

影响：
低利率刺激借贷，抑制储蓄；并向借款人传达错误的信号，即经济状况良好，投资可行

缺陷：
1. 美联储的决定基于政治考量而非经济因素
2. 前提：美联储的人要比市场更清楚什么是恰当的利率水平
```
