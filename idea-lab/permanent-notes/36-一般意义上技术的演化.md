>技术自行组织，自我创生，确有生命，不过是“珊瑚礁”意义上的有机体
# 组合
技术不同的构成方式，随技术数量的增加指数级上升
# 需求
技术在创造前不一定有可以被陈述的需求，但其出现必有诱因，称为“**机会利基**”

机会利基来自两个层次：
- 人类的需要：人类有遮挡，喂养，健康，穿衣，住房等需求，这和社会发展阶段有关
- 技术自身：
	1. 每个技术通过它的存在，建立一个更有效/更经济实现目的的机会
	2. 每项技术需要另外的支撑技术来制造它，这些支撑技术也需要自己的支撑技术
	3. 技术本身引发间接性的问题，产生解决方案的需求或者机会

# 核心机制
这里的**核心机制**，指一般意义上技术演化的机制
如果把单数技术视作节点，一般意义上的技术就是网络
网络中的节点可分为两类：
- 活性技术：蓄势待发，正在运用于经济中
- 死亡技术：过去曾经运用在技术中，但现在与将来不会。

在组合方面，活跃节点提供组合元素

在需求方面，
- 一方面，活跃节点促进社会发展，改变人类自身需求
- 另一方面，活跃节点自身提供需求

两者碰撞，在需求的引导下，不同的活跃技术被组合起来，形成新技术（促使新节点产生）

新技术产生后，对网络产生以下六点影响：
1. 成为一个新节点
2. 取代过去技术中的零部件
3. 产生进一步需求，即创造新的机会利基
4. 被取代零部件及其附属技术由“活跃技术”变为死亡技术，其产生的机会利基消亡
5. 作为未来技术或未来元素的前者元器件的新元素活跃起来
6. 社会经济会调整以适应这些步骤

实际上，这六点影响可以分为五类：
1. 对网络本身节点的影响
2. 对节点属性（活跃/死亡）的影响
3. 对机会利基的影响
4. 对“组合”的影响
5. 对外部经济的影响

所有影响是并行发生的
## 血崩式的毁灭与风潮
血崩式的毁灭：新技术不仅引起所替换的技术的崩溃，还引起依赖被替换技术的需求的崩溃，从属机会利基的崩溃，以及占据这些机会利基的技术的奔溃，其影响是血崩式的

风潮：新技术建立新的机会利基，等待更新的技术去占据它，而更新的技术会产生更新的机会利基…，成为风潮

# 技术进化与生物进化的比较
共性：两者都包含组合
区别：技术的基本进化方式是组合，而生物是变异
