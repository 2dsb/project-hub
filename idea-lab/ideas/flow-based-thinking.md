# Flow-Based Thinking Framework

## Trigger
Mindustry logistics design + school information flow + self-study knowledge flow → all three share the same underlying structure.

## Three Isomorphic Examples

| Domain | Source | Routing | Sink |
|------|-----|------|-----|
| Mindustry logistics | Drills | Conveyors / Routers | Core / Turrets |
| School information flow | Academic Affairs | Homeroom teacher / Grade group | Students |
| Self-study knowledge flow | Quality info sources | Filter / Integrate | Understanding / Output |

## Universal Analysis Framework
**To understand any system, ask three questions — where's the source? How does it route? Where does it go?**

Examine each segment: capacity, priority, congestion handling.

## Power
Doesn't matter if the system is physical, social, or cognitive — view it as a flow graph and you can immediately identify bottlenecks, redundancies, and single points of failure.

## Principle
This is essentially an application of analogical transfer — stripping away surface details from three domains to reveal the same directed graph topology (source → routing → sink).
