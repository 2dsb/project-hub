# Maintaining mental activity during low-energy states

Problem: When in a low state (e.g., mental_score < 30), you fall into a "no ideas" dysfunctional state. This goes beyond generating ideas — it extends to all kinds of mental activity: reading, thinking through problems, learning, decision-making — all become hard to initiate or sustain.

Core contradiction: Mental activities consume mental energy, and low-energy states are exactly when you're short on it. How can mental activity still happen without draining mental energy?

Goal: Find "low-energy versions" for different types of mental activity.

Breakdown by activity type:

| Activity Type | High-Energy Mode | Low-Energy Alternative |
|---------|---------|---------|
| Generate ideas | Active brainstorming, building from scratch | Answer preset questions, record fragmented observations, react to external input |
| Reading / learning | Deep reading + note-taking + connecting to existing knowledge | Skim / browse, listen to podcasts / audio, watch videos, read without recording |
| Think through problems | Systematic analysis, multi-angle reasoning | Only define the problem without solving, write down intuitive answers (without verifying), talk to yourself and record |
| Make decisions | Gather info + weigh pros and cons + compare options | Defer non-urgent decisions, just go with the "default option", use simple rules ("pick the first good-enough one") |
| Creative work | Design / write / code from scratch | Modify / improve existing work, organize materials instead of creating, imitate instead of originating |
