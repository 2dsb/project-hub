# X.com as Information Source

## Context

I now browse x.com (Twitter/X) to absorb information. Two questions follow:

1. How to use it effectively?
2. What other similar sources exist?

## Position in Flow-Based Thinking

x.com is a **Source** in the Source→Router→Sink pipeline. Its defining traits:

- **High noise, high velocity** — raw timeline is a firehose
- **Curation-dependent** — follow list = your filter. Quality is entirely determined by who you follow
- **Discovery role, not depth role** — x.com tells you "this thing exists"; it shouldn't be where you learn it

The bottleneck is not the Source itself — it's the **Router** layer that sits between x.com and your attention.

## How to Use It

| Tactic | Description |
|--------|-------------|
| **Follow list as curation** | Unfollow anyone you skip past 3 times in a row. Signal, not obligation. |
| **AI as Router** | Feed a day's timeline to AI → extract 3-5 items worth deep-reading → discard the rest |
| **Role discipline** | x.com = discovery (finding new papers, tools, discussions). Do NOT expect to learn anything deeply from it. |
| **Time cap** | Set a hard limit. Infinite scroll is designed to defeat you. |

## Similar Information Sources

Sources with comparable characteristics (real-time, public, curation-by-follow/community):

| Source | Content Bias | Noise Level | Filter Mechanism |
|--------|-------------|-------------|-----------------|
| Reddit (r/MachineLearning, etc.) | Paper discussion, technical Q&A | Medium | Community voting |
| Hacker News | Tech/startup/engineering | Medium-low | Community voting + mods |
| GitHub Trending | New projects, tools | Low | Activity metrics |
| arXiv / Papers With Code | Research papers | Low (needs quality judgment) | Author submission |
| Zhihu / SSPAI | Chinese long-form content | Medium | Follow + algorithm |
| Discord/Slack communities | Real-time discussion | High | Community norms |

### Key Distinction

- **x.com** → what people *you chose* are saying (personal curation)
- **Reddit / HN** → what a *community* voted to surface (collective curation)
- **arXiv** → what *authors themselves* deemed worth publishing (self-curation)

Three different filtering mechanisms. They complement each other — no single one covers all signal.
