# Data → Pattern → Prediction Chain

## The Chain

```
data → pattern → prediction
```

Three stages, each abstracting from the previous:

- **Data** — raw observations, unprocessed. The ground.
- **Pattern** — regularities extracted from data. Compression. "What repeats?"
- **Prediction** — applying patterns to unseen situations. "What comes next?"

## Why This Matters

This chain appears everywhere:

| Domain | Data | Pattern | Prediction |
|--------|------|---------|------------|
| Science | Experiment results | Theory/law | Hypothesis |
| ML | Training set | Model weights | Inference |
| Learning | Reading/experience | Understanding | Application to new problems |
| Conversation | What was said | Topic structure | Where the conversation is going |
| Life | Daily events | Behavioral patterns | Future outcomes |

The chain is the same — only the substrate changes.

- **Flow-based thinking**: this chain is the cognitive layer underneath the flow topology
- **Project structure (M, A)**: M (memory) is the pattern layer — compressed data. The reconnection doc is a pattern artifact.
