# Applicability Conditions for Analogical Transfer

## Trigger
Noticed myself doing a "me → intern → company" → "unschooled person → me → school" transfer, and wondered when transfer actually works.

## Core Judgment
**What transfers is relational structure; what doesn't transfer is surface features.** This transfer succeeded because all surface labels were stripped away, leaving only the abstract skeleton — "an insider attempting to convey complex system knowledge to an outsider using only language."

## Check Criteria
Express the situation as "X did what to Y" or "the relationship between A and B" — if the relationship still holds after swapping out the concrete entities → transfer applies.

## When Migration Fails
Surface similarity but different underlying relationships (company meeting = power games + signaling; class meeting = one-way broadcast) → forcing the transfer distorts it.

## Concise Version
**Transfer works if and only if you're transferring topology, not node labels.**
