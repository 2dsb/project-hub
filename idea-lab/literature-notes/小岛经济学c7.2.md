>公共事业的建立

公共事业（公司）建立，与个人，公司建立契约

行为：公司建立
```
A1，A2……等若干人建立了公司，并与投入劳动，资本，积蓄；并银行签订契约借款或吸引投资，创立了公司CC
CC用劳动，积蓄和资本创造了资本，产生生产（物品或服务），通过与个人的契约获得劳动，资金
```
影响：
```
经济层面：
1. 主体特征的改变：改变了每个人的消费
2. 契约：增加了就业岗位
非经济层面：
3. 满足了饮水/用水需求
4. 创造了新的产业
```


自来水厂和岛民的契约：
1. 劳动契约：增加了100多名工人维护复杂的供水系统
2. 物品/服务契约：用自来水和资金交换

影响：
1. 自来水收费合理，导致远离水源的地方也能用上水，以前的不毛之地也能种庄稼了
2. 水管内水流平稳，可以用来推动机器，催生了新的产业
