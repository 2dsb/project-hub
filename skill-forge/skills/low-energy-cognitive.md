# 低能量思维维持

**触发条件**：
1. 手动：用户说"低能量思考模式"、"脑子转不动了"、"没法思考"、"想不出来"等思维相关短语
2. 自动探测：AI 在对话中检测到用户在认知活动上反复卡住（逃避标记、挫败表达、陷入循环、放弃尝试），且最近 3 条用户消息中出现 2 种以上不同的卡住信号时，主动提议

**与 low-energy-day.md 的关系**：独立对等 skill。low-energy-day.md 管理全天的身体节奏和活动结构（触发条件：mental_score < 30 或 physical_score < 40）；本 skill 专门管理思维/认知活动，按对话行为模式触发。两者可在同一天同时激活，互不冲突。

**核心原则**：低能状态下，思维的目标不是"产出质量"，而是"维持思维不熄火"。一个碎片想法好过零想法。一个直觉答案好过放弃思考。

**设计理念**：AI 是脚手架，不是思考者。AI 提供结构和选项，用户决定做什么、做到什么程度。本 skill 的触发短语包含"思考"、"想"、"脑子"等关键词，与 low-energy-day.md 的"低能量模式"（整体能量）区分。

## 离线

**我的职责**：

1. **维护资源指针**——为每种认知活动准备"低能耗替代"所需的起点材料。低能状态下不应现找素材。

### 资源指针（按活动类型）

详细的 5 种活动类型及其高能/低能替代说明见 [ideas/low-energy-ideation.md](../ideas/low-energy-ideation.md)。下表仅列出每种类型的资源位置和维护方式：

| 活动类型 | 资源自然位置 | 已有种子示例 | 维护方式 |
|---------|------------|-------------|---------|
| 产生想法 | `ideas/*.md` | `ideas/low-energy-ideation.md` 中的预设问题（见下方） | 用户定期向 `ideas/` 添加新想法；AI 从 ideas/ 中提取适合低能状态回答的预设问题 |
| 阅读/学习 | `resources/` 目录下的材料 | `resources/running-training/`（Daniels' Running Formula 4 部分）；`resources/ai-ability/ai-ability-10-levels.md`；`resources/project-hub/`（v2-v6.2 设计文档） | 用户添加新材料到 resources/；**TBD**：建议创建 `resources/reading-list.md` 作为集中阅读清单 |
| 思考问题 | `ideas/*.md` | 项目的 parent_project 层级定义问题 | 用户在 ideas/ 或通过项目层级定义问题后，低能状态下用来练习"只定义不求解" |
| 做决策 | 分散在各项目/领域文件中 | — | **TBD**：建议创建 `resources/decision-rules.md` 集中记录默认决策规则。用户在日常中积累规则（如"非紧急→推迟"、"选第一个够好的"）；AI 在低能状态下引导用户应用已有规则 |
| 创造性工作 | `projects/` 下的项目文件 | `projects/gaokao-math.md`、`projects/gaokao-chinese.md`、`projects/project-hub.md`、`projects/running-training.md`、`projects/ai-ability.md` | 用户维护项目进展；低能状态下对已有产出做"修改/整理/优化"而非"从零创作" |

2. **种子示例**——以下内容供 AI 在低能状态下直接使用，无需用户当场想：

   **产生想法 — 预设问题**（低能状态下只需回答，不需提出）：
   - 今天有什么让我意外的事？
   - 最近卡住我的一个问题是？
   - 如果只做一件事就能让我更接近目标，那是什么？
   - 最近看到/听到的哪个东西让我有"这也是我想做的"感觉？
   - 有没有我觉得"理所当然"但可能不是的事？
   - 今天有什么是"还行但可以更好"的？
   - 有没有什么小事，做了会让今天收尾更舒服？

   **做决策 — 默认规则**（低能状态下不分析，用规则）：
   - 非紧急决策 → 推迟 24 小时，记到 daily 的反思区等待
   - 可逆决策 → 用"第一个够好的"原则，选了就选了
   - 只有两个选项 → 在脑内抛硬币，如果对"结果"感到失望就选另一个
   - 信息不足 → 不决定，定义"需要知道什么才能决定"（一句话写在 daily）
   - 情绪波动时的大决定 → 默认不做，等 24 小时

   **阅读/学习 — 材料指针**（低能状态下翻阅或听，不记笔记）：
   - 跑步训练体系：`resources/running-training/part1_1-72/` 至 `part4_217-286/`
   - AI 能力分级框架：`resources/ai-ability/ai-ability-10-levels.md`
   - 项目管理中枢设计文档：`resources/project-hub/`（v2 至 v6.2 各版本规格书）
   - 外部链接索引：`resources/project-hub/links.md`
   - **TBD**：创建 `resources/reading-list.md` 集中管理所有阅读材料（含纸质书、播客、课程）

3. **轻提醒**：低能状态下，思考的目标不是"想清楚"，是"想了"。不要求完整，不要求正确。AI 不会评价你的想法质量。

## 在线

### 触发时机

**手动触发**——用户说出以下任一短语（支持模糊匹配，核心关键词命中即可）：
- "低能量思考模式"（推荐主要触发词，含"思考"关键词与 low-energy-day.md 的"低能量模式"区分）
- "脑子转不动了"
- "没法思考"
- "想不出来"

**注意**：用户只说"低能量模式"（无"思考"关键词）触发的是 low-energy-day.md，不是本 skill。本 skill 需要思维相关的短语。如果用户说了"低能量模式"但实际想启动本 skill，AI 应确认："你是想启动低能量日模式，还是低能量思考模式？"

**自动探测触发**——AI 在阅读用户最近 3 条消息时，检测到 2 种以上以下卡住信号：
- 反复说"我不知道"或"想不出来"（≥2 次）
- 挫败表达（"算了"、"不做了"、"放弃了"、"太难了"）
- 陷入循环（反复问同一个问题、反复修改同一内容不推进）
- 任务放弃模式（从尝试某类认知活动直接跳到无关话题）

**阈值设计理由**：2+ 种不同信号（非同一信号的重复次数）在最近 3 条消息内。避免单次"我不知道"误触发（正常对话中常见），同时确保连续卡住能被及时捕捉。

**触发后模式判定**：
1. 读取当日 daily 文件（`daily/YYYY-MM-DD.md`），搜索 `## 今日节奏（低能量日` 标记
2. 找到 → `mode: integrated`（low-energy-day.md 当天已激活，启用槽位集成）
3. 未找到 → `mode: standalone`（正常日，轻量独立干预，不接入槽位）
4. 若当日 daily 文件尚不存在 → `mode: standalone`（连 daily 都还没创建，说明一天刚开始或系统未完全启动，不假设低能量日已激活）

**退出机制**（误触发保护）：
- 用户说"不需要"、"不用了"、"算了" → 立即退出，不追问
- 用户连续 2 次对 Ask 步骤说"不是"或选"以上都不是" → 退出
- AI 退出时说："好的，需要的时候说'低能量思考模式'。"不解释、不挽留

### 输出格式

每次低能量思维活动结束后，追加到当日 daily 文件的 `#### 低能量思考记录`（位于 `## 想法与笔记` → `### 反思` 下）：

```
#### 低能量思考记录
- 活动类型: [5 种之一]
- 低能替代: [使用的具体替代方式]
- 做了什么: [1-2 句事实描述]
- 一句话: [用户的 1 句回访原话或概括]
```

示例：
```
#### 低能量思考记录
- 活动类型: 阅读/学习
- 低能替代: 翻阅 Daniels' Running Formula 第 3 章，只读不记
- 做了什么: 翻看了 VDOT 配速表部分，读了 5 页，没有做笔记
- 一句话: 还行，以前没注意配速和训练强度的对应关系
```

同一日内多次触发时，新记录追加在同标题下，每条记录之间空一行。不覆盖已有记录。

### 槽位集成机制

当 `mode: integrated`（low-energy-day.md 当天已激活），本 skill 通过以下机制定位当前槽位：

**槽位探测（3 层）**：

1. **主要方式——读取 daily 文件**：搜索当日 daily 文件中的 `## 今日节奏（低能量日` 标题，在该区块内查找低能量日节奏框架标记（📖、🌙 等 emoji 前缀），根据时间上下文或最近操作推断用户当前所处的槽位。读取 daily 文件是非侵入式的——使用的是两个 skill 已经共享的文件产物。

2. **回退方式——询问用户**：如果 daily 文件中找不到节奏框架标记（例如 low-energy-day.md 的 Step 3 尚未写入），或者槽位状态不明确（用户在非标准时间段活动），直接问用户："你现在在哪个时间段？"并将低能量日的槽位选项列出（📖第三站：安静的输入 / 🌙收尾：安静的晚间 / 其他）。

3. **匹配逻辑**：
   - 当前槽位 = 📖第三站 且用户选择"阅读/学习" → Guide 步骤用低能阅读替代替换第三站的默认输入选项
   - 当前槽位 = 🌙收尾 且用户选择"产生想法"或"创造性工作" → Guide 步骤用输出导向替代填充收尾槽
   - 当前槽位 = 其他槽（出门/体能/动手/保底）→ 不介入槽位，但仍提供独立的低能认知引导
   - 当前槽位与用户选择的活动类型不匹配 → 不强行接入，该槽位保留 low-energy-day.md 的默认行为，本 skill 独立引导

**非干扰原则**：本 skill 永远不修改 low-energy-day.md 写入的节奏框架结构。只在自己适用的槽位内丰富内容。不适用时退回到独立模式。

### 补充规则

- 本 skill 不替代危机模式（physical < 30 触发 M18 危机模式，行为完全不同）
- 如果 low-energy-day.md 当天未激活但 mental_score < 30，AI 可主动建议："今天是低能量日吗？要不要也启动低能量日模式？"但不强制
- 如果连续 2 天触发本 skill 且用户每次都选同一活动类型，AI 在下一次触发时把该类型的替代作为默认选项前置
- **不追踪进度**：低能认知活动不考核 completion，只记录"做了"
- **用户自主权**：用户说"换一个类型"→ 回到 Step 2 重新选择。用户说"换一种方式"→ Step 3 提供同一类型的另一种替代。用户说"不做了"→ 立即退出
- **AI 不问"为什么"**：在低能状态下，"为什么做不下去"的分析本身就是认知负担。AI 只提供替代路径，不分析原因
