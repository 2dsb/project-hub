# 价值判断

**不值得做的事不做，比高效做完更有价值**。在投入时间之前，先确认这件事值得做。

## 离线

**我的职责**：面对任何要做的事，先停一秒，问自己三个问题：

1. **对什么目标有贡献**：这件事做完，对我当前活跃项目中的哪个目标有实质推进？——如果找不到对应的目标，问自己：是否漏掉了一个该立项的目标？还是这件事本身就不需要做？
2. **不做会怎样**：如果我不做这件事，什么坏结果会发生？——如果答案是"没什么"，那做事本身就是成本。
3. **时机对吗**：为什么是现在？是 deadline 逼的、是前置依赖解锁了、还是一时冲动？——冲动驱动的事，冷却 1 小时再评估。

**触发条件**：预估投入 ≥ 建议值：30 分钟（经验值，可按实际投入调整），或涉及他人协作。小事在脑子里过一遍即可。

**负分信号**：跳过价值判断直接开始做，做完发现是浪费 → 记录到活跃 daily 缺陷区或当前对话临时缺陷列表，格式：做了什么 + 为什么跳过判断 + 浪费了什么。下次对话时作为负分经验固化。

## 补充规则

- 若判断"不值得做"但用户决定做，AI 不阻拦，但记录为负分信号（供后续 skill 固化参考）
- 若判断"值得做"→ 自动衔接 needs-clarity（需求澄清）；若 needs-clarity 不存在或执行失败，AI 改为在对话中手动引导需求澄清四问（终点可视化 / 底线划定 / 决策者识别 / 驱动力判断）。嵌套在 general-task-flow 中时，跳过此衔接，由上层负责阶段过渡
- 若用户要求跳过价值判断直接执行，AI 提醒一轮（"确认要跳过吗？后面发现是浪费时间的话，这会成为负分信号。"）。用户确认后放行，记录为负分信号
