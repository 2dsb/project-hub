# 探究式作文辅助

**触发条件**：用户说出作文题目/核心概念，并说"帮我分析题目""探究式写作""概念分析""帮我理一下怎么写"。

**核心原则**：AI 的角色是"收束前的发散器"——帮助拓展思考边界，但不替用户做判断和缝合。收束和缝合是人做的事。写作的控制力不来自结构框架（三段论），而来自概念清晰度——边界越清楚，写得越稳。

**配对 skill**：[连接导向阅读辅助](connection-reading.md) — 同一个概念约束图，阅读 skill 帮你提取（解网），写作 skill 帮你构建（织网）。

## 离线

**用户职责**：

1. **准备作文题目/核心概念**：明确要写的话题，提炼出核心词。如果题目本身模糊，先自己尝试缩小范围。
2. **执行实际写作**：AI 辅助前三步中的前两步（概念域清晰化 + 多角度切入），第三步（自然缝合）和实际成文由用户独立完成。
3. **判断内容域饱和度**：当 AI 在第一步中提问时，用户需要自己判断"我的内容域是否已经足够清晰"——连续举出 3 个新例子但都落入已有规律、没有修正规律时，内容域基本饱和。
4. **判断角度覆盖率**：在第二步中，用户自己判断哪些角度对当前题目有价值，哪些可以跳过。不是所有角度都要用——选最能揭示题目深层结构的 2-3 个角度即可。
5. **使用概念约束图**：在第一步和第二步中，可以同时构建概念约束图（节点=核心概念，边=约束关系），这张图就是第三步缝合时的路线图。

**关键心态**：AI 帮你发散，你负责收束。发散是为了不让思维被惯性框架限制，收束是为了不让文章散掉。两个能力缺一不可。

## 在线

### 触发时机

- 用户说出作文题目/核心概念，并说"帮我分析""探究式写作""概念分析"
- 用户在写作准备阶段说"这个词具体指什么""还有什么角度可以考虑"
- 用户在 connection-reading 完成后，想把概念约束图用于写作

### Steps

- order: 1
  action: "概念域清晰化（第一步）。用户给出作文题目/核心词后，启动概念穷举循环：\n\n(1) **初始提问**：'这个词的内涵（本质含义）和外延（所有可能的指代对象）分别是什么？先说说你目前的理解。'\n\n(2) **举例 + 总结循环**：引导用户不断举出该概念的具体例子，从例子中提炼规律，用规律检验更多例子。AI 在循环中扮演'提问加速器'——通过以下四个穷举策略帮助用户发现遗漏：\n  - **类比跳跃**：'看一个完全不同领域的情况——[领域 X] 里有没有类似的东西？这算不算这个词的范畴？'\n  - **极端测试**：'如果把 [某个条件] 推到极致，还算不算？'\n  - **反向提问**：'什么肯定不是这个词的指代对象？用排除法收缩边界。'\n  - **维度穷举**：按维度（规模、主体、时间尺度、是否自愿等）分类检查——'[维度 Y] 的两极你都有例子覆盖吗？'\n\n(3) **饱和判断**：当用户连续举出 3 个新例子但都落入已有规律、没有修正规律时，告知用户：'内容域基本饱和。'\n\n(4) **准确性检验**（用户提炼出内涵定义后）：\n  - 反例测试：'有没有一个东西是 X 但不符合你的定义？或符合你的定义但明显不是 X？'\n  - 替换测试：'把你的定义替换回原概念所在的语境，含义变了吗？'\n  - 精简测试：'尝试删掉定义中的某个子条件，还能准确区分 X 和非 X 吗？能删掉的就不是本质。'\n\n(5) **产出**：一个经过检验的概念域清晰化结果（内涵定义 + 外延范围 + 边界模糊地带标注）。同时生成初步的概念约束图——当前已识别的概念节点和它们之间的约束关系。"
  note: "AI 在这一步不提供答案——只提问。每个问题都是为了帮用户发现自己的理解盲区。目的不是找到'哲学家会同意的定义'，而是找到'写这篇作文时能站得住的、经得起反例攻击的定义'。本步骤包含 5 个子阶段（初始提问→举例循环→饱和判断→准确性检验→产出）——必须逐子项执行，不可跳过或合并。"
  execute_skill: null
  skill_args: {}
  on_failure: "prompt"

- order: 2
  action: "多角度切入回答（第二步）。基于第一步产出的概念域和问题列表，AI 从不同角度提示可能的回答方向：\n\n(1) **角度菜单**：展示 7 个角度维度，让用户选择感兴趣的 2-3 个（不是全部都要用）：\n  - 正面 / 反面\n  - 个体 / 社会\n  - 历史 / 当下 / 未来\n  - 理论 / 实践\n  - 理性 / 情感\n  - 局部 / 全局\n  - 静态结构 / 动态变化\n\n(2) **逐角度展开**：对用户选择的每个角度，AI 提出引导性问题（不提供具体回答内容）：\n  - 例如选择'正面/反面'→ '从这个角度看，支持/反对的论据分别有哪些？对立面有没有合理的部分？'\n  - 例如选择'个体/社会'→ '对个人来说意味着什么？放到社会层面，同样的逻辑还成立吗？'\n  - 例如选择'历史/当下/未来'→ '这个问题的根源在哪个时间点？现在的状态是必然的吗？趋势在往哪个方向走？'\n\n(3) **约束关系映射**：每打开一个角度，AI 提示用户将新的认识映射到概念约束图中：'这个角度给你的概念约束图增加了什么新的边？还是修正了已有的边？'\n\n(4) **角度饱和判断**：当新角度不再产生新的约束边（只重复已有关系），告知用户：'这个方向的角度已经饱和，可以换方向或进入缝合阶段。'\n\n(5) **产出**：扩张后的概念约束图（节点 = 概念，边 = 约束关系类型 + 来自哪个角度），这张图就是第三步缝合时的路线图。"
  note: "AI 的角色是角度提示器——提供方向，不提供内容。用户自己决定每个角度下具体说什么。如果用户在某角度下卡住，AI 可以拆分问题降低难度（比如把'从社会角度看'拆成'从制度角度看''从文化角度看''从经济角度看'），但仍不提供具体答案。本步骤包含 5 个子阶段（角度菜单→逐角度展开→约束关系映射→角度饱和判断→产出）——必须逐子项执行，不可跳过或合并。"
  execute_skill: null
  skill_args: {}
  on_failure: "prompt"

- order: 3
  action: "明确 AI 不介入边界（第三步）。告知用户：\n\n'第三步——自然缝合——是你的事。现在你手上有一张概念约束图：\n- 节点 = 你清晰定义过的概念\n- 边 = 你从多个角度确认过的约束关系\n- 每个边都有明确的约束类型和来源角度\n\n缝合就是把这张图翻译成自然语言——找到一个起点概念，沿着约束边走到下一个概念，让论证流自然展开。这不是 AI 能替代的事，因为：(1) 缝合的语言风格是你的声音，不是 AI 的；(2) 缝合的节奏和张力控制是写作的核心能力，需要刻意练习；(3) 只有你自己知道哪个起点最有话可说。\n\n如果缝合中卡住了，可以回来问我具体问题——比如"这两个概念之间的过渡怎么写"——但我会提供结构建议，不替你写。'\n\n如果用户在 connection-reading 中已有相关主题的概念约束图，提醒：'你之前在阅读中提取的概念约束图可以作为参考——同一主题，别人是怎么建立约束的？你的图和阅读的图有什么异同？'"
  note: "这一步的核心是划清边界——不是 AI 不愿意帮，而是缝合能力必须在人脑里长出来，AI 替你做就是剥夺了你的练习机会。"

  skill_args: {}
  on_failure: "prompt"

## 补充规则

- 用户说"这个概念我不太确定"→ 回到步骤 1，针对该概念重新走举例+总结循环
- 用户说"我没有想法""头脑一片空白"→ AI 从最接近日常生活的角度切入（"那你身边有没有类似的例子？"），从具体到抽象，不直接问抽象问题
- 用户已经有一张概念约束图（来自 connection-reading）→ 直接进入步骤 2，用已有图作为基线
- 约束类型库是共享的——如果在写作的概念域清晰化（Step 1）或多角度展开（Step 2）中发现了新的约束关系类型，写作结束后按以下流程补充到 [shared/constraint-types.md](shared/constraint-types.md)：(1) 列出写作中出现的、但 constraint-types.md 中未定义的新约束关系；(2) 该类型在本次写作中出现 ≥2 个不同角度/用例 → 值得纳入（写作中自然出现的约束类型复用价值高）；(3) 按扩展机制（暂停→命名→定义→追加）写入；(4) 告知用户新增了什么类型。用户说"整理新出现的约束"时也可独立触发此流程。注意：写作中发现的新类型以"概念间关系"为主（对应 constraint-types.md），结构层面新类型（对应 text-structure-types.md）主要在阅读端发现。
- 作文题目本身是高考导向的 → AI 应理解高考作文的评分要求，但不以此限制概念探索的广度（先发散，再收束时考虑应试约束）
