# The Stranger Conversation Loop

## The Pattern

When approaching someone you don't know:

```
Greet → Ask a question → Listen to their answer → (Express view + Ask follow-up) → Loop
```

A cyclical algorithm: each answer becomes the input for the next question. The loop sustains itself as long as curiosity holds.

## Why It Works

- **Ask first, not tell** — lowers the barrier for the other person. People are better at answering than initiating.
- **Listen before expressing** — your response is grounded in what they actually said, not a pre-planned script.
- **The loop is self-feeding** — each answer contains threads you can pull on for the next question. No awkward silences when the thread runs out.

## When to Use

- First meeting at events, conferences, networking sessions
- Talking to someone significantly more senior (the question-first pattern is naturally deferential)
- Any situation where you don't know what the other person wants to talk about — let them lead
